# 15. Terimler Sözlüğü

| Terim | Açıklama |
|-------|----------|
| **DWH** | Tarihsel ve analitik kullanım için yapılandırılmış veri ambarı |
| **OLTP** | Güncel operasyonel işlemleri yöneten kaynak sistem |
| **NL2SQL** | Doğal dil talebinden SQL taslağı oluşturma yaklaşımı |
| **Query Builder** | Tanımlı kurallar ve şablonlarla deterministik sorgu üretimi |
| **Semantic Model** | KPI, metric, dimension ve ilişkilerin Power BI katmanındaki kurumsal tanımı |
| **RLS** | Power BI Row-Level Security; kullanıcının görebileceği satırları sınırlar |
| **Guardrail** | Sorgu ve veri erişimini deterministik kurallarla sınırlandıran kontrol katmanı |
| **Canonical Request** | Doğal dil talebinin metric, dimension, filter ve tarih aralığına ayrıştırılmış yapılandırılmış hali |
| **Allow-list** | Sorgulanmasına izin verilen tablo, kolon, görünüm ve JOIN yollarının açık listesi |
| **Veri Kapsamı (Data Scope)** | Kullanıcının erişebileceği veri sınırı: şirket, bölge, mağaza, departman |
| **Request ID** | Bir talebi uçtan uca izlemeye yarayan korelasyon kimliği |
| **Grain** | Sonuç setinin detay seviyesi (gün/ay, mağaza/bölge gibi) |
